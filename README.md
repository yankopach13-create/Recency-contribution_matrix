# Recency Contribution Matrix

Streamlit-приложение: вклад продаж в выбранном **периоде** по **давности предыдущей покупки** (до начала периода).

## Данные в `base/`

Excel (`.xlsx`), в имени файла желательно указать **год и русский месяц** (например `2024 январь.xlsx`, `2024 январь 2.xlsx`), чтобы приложение не читало лишние месяцы при скане истории.

**Колонки в каждом файле:**

`Группа1`, `Группа2`, `Группа3`, `Дата`, `Продажи`, `Количество чеков`, `Количество товар` (допускается `Количество товара`), `Код клиента`.

## Логика

1. Задаётся **период анализа**: ввод день·месяц·год с **автопереходом** между полями (клавиатура), затем **Применить даты**. Кнопка **Сменить даты** сбрасывает период.
2. **Загрузить категории по периоду** — читаются только файлы, пересекающиеся с этим периодом; из них строятся списки Группа1–3.
3. **Посчитать** — для клиентов, купивших в периоде (с учётом категорий), по **всей папке `base/`** ищется последняя покупка **строго до первого дня периода** (вне категорий). Сегменты: **старше календарного года до начала анализа** — по **кварталам** (C1–C4); **в пределах этого года** — по **месяцам**. Без покупок до начала периода — **«Новые клиенты»**. Пустой код — **«Клиенты без БК»**.

На больших объёмах шаг **Посчитать** может занимать много минут.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой Streamlit Cloud

Подключить репозиторий, главный файл — `app.py`. Папка `base/` с Excel должна быть в репозитории (или подключаться иначе).
