# Recency Contribution Matrix

Streamlit-приложение: вклад продаж в выбранном **периоде** по **давности предыдущей покупки** (до начала периода).

## Данные в `base/`

Excel (`.xlsx`), в имени файла желательно указать **год и русский месяц** (например `2024 январь.xlsx`, `2024 январь 2.xlsx`), чтобы приложение не читало лишние месяцы при скане истории.

**Колонки в каждом файле:**

`Группа1`, `Группа2`, `Группа3`, `Дата`, `Продажи`, `Количество чеков`, `Количество товар` (допускается `Количество товара`), `Код клиента`.

## Логика

1. **Период** — кнопка **Отобрать период для анализа** в `date_segment_picker/`: только **реальные** даты, без будущих, период **внутри** диапазона по именам файлов в `base/`. Нужен **PyArrow**.
2. **Отбор товаров** — три уровня (Группа1–3) в один ряд; в каждом можно выбрать **несколько** значений (пусто = все на этом уровне).
3. **Применить все фильтры для анализа** — для клиентов, купивших в периоде (с учётом отбора), по **всей папке `base/`** ищется последняя покупка **строго до первого дня периода** (вне категорий). Сегменты реценси формируются **по месяцам**. Без покупок до начала периода — **«Новые клиенты»**. Пустой код — **«Клиенты без БК»**.

На больших объёмах этот шаг может занимать много минут.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Деплой Streamlit Cloud

Подключить репозиторий, главный файл — `app.py`. Папка `base/` с Excel должна быть в репозитории (или подключаться иначе).
